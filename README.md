# My Life for Windows – build and update feed

This branch only builds the My Life Windows app and publishes it to the `my-life-desktop` release, which installed copies check for updates.
The source of truth is a private repo; this copy (app code and screens only, no keys or sign-ins) is pushed here for each release.

Install: https://github.com/lostak/powder-report/releases/download/my-life-desktop/MyLife-Setup.exe
